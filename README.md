# Systems-Lab

[Open Systems-Lab](https://polarvapourer.github.io/Systems-Lab/)

An independent revision workbook for ECS404U Computer Systems and Networks. It covers the supplied teaching weeks 1–6, 8 and 9, from integer representation and memory circuits to IEEE 754 and MIPS assembly.

- **Practice** generates questions with hints, answer checking and worked solutions.
- **Mock paper** gives eight mixed questions with optional timing and a marked review.
- **Bit explorer** lets you edit a byte and compare unsigned, signed and hexadecimal interpretations.
- **Progress** records first checks in the current browser.

The questions are original practice material. There are no accounts, analytics or third-party assets. Answers and progress are saved in browser local storage.

Open index.html directly or serve the repository root with `python -m http.server 8000`.

The root .gitignore excludes all files by default and explicitly allows the published site files. When adding a new public asset, review it and add its exact path to .gitignore.
