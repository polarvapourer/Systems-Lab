# Systems-Lab

[Open the ECS404U workbook](https://polarvapourer.github.io/Systems-Lab/)

The workbook opens on the concept guide. Choose a teaching week and switch between **Learn**, **Practice** and **Explore**. It covers weeks 1–6, 8 and 9 of Computer Systems and Networks. The explanations, annotated examples, retrieval checks and reading references are available without signing in.

- **Workspace** has 32 fixed exercises, including select-all concept questions, hints, partial-answer feedback and worked answers. Change the inputs under Explore to test a different case.
- **Generator** makes 1–100 distinct instances from a topic or mixed revision. Choose accessible, moderate, stretch or mixed difficulty. A seed reproduces the same set. Share a question or set link, play through the steps, or print questions and solutions separately.
- **Paper practice** offers 32 written questions with suggested marks. Build a topic or mixed paper, work with optional guidance or a timer, and self-mark each criterion. Review missed marks, try variations, print separate sheets, or share and import/export the question selection.
- **Systems calculator** checks custom fixed-width expressions and editable problems across all eight weeks. Python 3 checks use the displayed inputs and standard library only.
- **Progress** is local to the browser. Shared links and paper files contain the question selection. The original quick drills, bit explorer and earlier scores are accessible from the footer.

The generator, paper practice and Python panel adapt the interaction patterns and code from [Discrete Lab](https://github.com/polarvapourer/discrete-lab). These ECS404U exercises and suggested marks are independent student revision material.

Run `python -m http.server 8000` in the repository root and visit `http://localhost:8000/`. GitHub Pages serves the same static files. The root .gitignore allows only explicitly named public files. Original module documents are kept outside this repository.
